2. Ordenação:
Uma vez que o heap máximo
tenha sido construído, o maior
elemento estará sempre na raiz
da árvore (posição 0 do array).
Esse elemento é trocado com o último
elemento do array, que agora está na
posição correta
Em seguida, o heap é reconstruído
sem o último elemento, que já está na
posição correta.

void heapSort(int vetor[], int tamanho){
    build_heap(vetor, tamanho);
 
    for(int i = tamanho - 1; i > 0; i--){
        trocar(&vetor[0], &vetor[i]);
     
        max_heapify(vetor, i, 0);
    }
 
}

O procedimento Heap Sort demora o tempo O(n log n),
já que a chamada a Build Max-Heap demora o tempo
O(n), e cada uma das n — 1 chamadas a Max-Heapify
demora o tempo O(log n).
ESTÁVEL OU
ADAPTATIVO?
Nenhum dos dois!!
1.
Por que não é estável?
O Heap Sort (a menos que seja
implementado de modo especial), não
preserva a ordem de elementos
iguais, ou seja, não é estável
2.
Por que não é adaptativo?
Não é adaptativo, pois independente
da ordem prévia de seus elementos,
manterá complexidade assintótica O(n
log n).
